# Security Policy

We are committed to securing our project and releasing regular updates. Below is the list of currently supported versions with security patches.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

We take the security of our project very seriously. If you believe you have found a security vulnerability, please **do not open a public GitHub issue**. Instead, report it privately.

### How to Report?
* **Email:** Send details to our security team at [rootinfinet@gmail.com]
* **Private Discussion:** Alternatively, you can use GitHub's private vulnerability reporting feature on our repository.

### What to Expect?
* **Acknowledgment:** You will receive an initial response acknowledging your report within **48 hours**.
* **Updates:** We will provide regular updates on our progress regarding the reported vulnerability every **3 to 5 business days**.
* **Resolution / Disclosure:** If the vulnerability is accepted, we will work on a fix and coordinate with you on a public disclosure timeline once the patch is released. If it is declined, we will provide a clear explanation why.

Thank you for helping keep our project safe and secure!
